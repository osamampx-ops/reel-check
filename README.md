# فحص الريل · reel-check

أداة مجانية بتشتغل مع **Claude Code**: بتفحص الريل قبل ما تنزّلو، وبتعطيه علامة من 100، وبتقلّك وين الناس رح تقلب وشو تعدّل.

## شو بتفحص
| الجزء | العلامة |
|---|---|
| الهوك (أول 3 ثواني) | 30 |
| الإيقاع | 20 |
| النص على الشاشة | 15 |
| الصوت | 15 |
| القصة | 10 |
| الـ CTA والـ loop | 10 |

## التثبيت
1. لازم يكون عندك [Claude Code](https://claude.com/claude-code) و ffmpeg (وكمان yt-dlp إذا بدك تفحص رابط).
2. نزّل المجلد هاد (Code ← Download ZIP) وحطّو هون:
   - ويندوز: `C:\Users\<اسمك>\.claude\skills\reel-check`
   - ماك/لينكس: `~/.claude/skills/reel-check`
3. افتح Claude Code وابعتلو الريل (ملف أو رابط) واكتب: **افحص** أو `/reel-check`
